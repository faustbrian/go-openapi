# Documentation

`openapi` parses, models, validates, transforms, and compares Swagger and
OpenAPI documents. Start with the README quickstart, then use the sections
below for deeper contracts.

- [Go package reference](https://pkg.go.dev/github.com/faustbrian/go-openapi)
- [Detailed feature reference](reference.md)
- [Specification decisions](specification-decisions.md)
- [Interoperability](interoperability.md)

The public packages expose focused surfaces for parsing, validation, typed
views, references, media handling, serialization, filtering, composition,
conversion, and compatibility diffing. Package-level Go documentation is the
authoritative API reference.
